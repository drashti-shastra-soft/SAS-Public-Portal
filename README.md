# 🛡️ Secure Assurance Services – Public Portal

**Secure Assurance Services (SAS)** is a responsive public website designed to showcase financial planning, investment solutions, life insurance, and general insurance services.

The portal helps visitors explore financial products, understand available services, view company achievements, and connect with the team for personalized assistance.

## 🌐 Live Website

**Visit Website:** [https://secureassuranceservice.in/](https://secureassuranceservice.in/)

## ✨ Key Features

- **Home Page:** Professional introduction to Secure Assurance Services.
- **About Us:** Information about the company and its financial services.
- **Investment Services:** Showcases investment and savings solutions.
- **Life Insurance:** Provides information about life insurance plans.
- **General Insurance:** Displays different general insurance solutions.
- **Product Information:** Dedicated pages for different financial products.
- **Portfolio:** Displays certificates, achievements, and recognitions.
- **Frequently Asked Questions:** Provides answers to common insurance and investment questions.
- **Contact Us:** Displays company contact information and inquiry options.
- **Online Inquiry:** Allows visitors to submit their questions and requests.
- **Responsive Design:** Provides a user-friendly experience across desktop, tablet, and mobile devices.
- **SEO-Friendly Website:** Helps improve online visibility.

## ⚙️ Getting Started

### Prerequisites

- Visual Studio
- Compatible .NET SDK / Targeting Pack
- NuGet Package Manager
- Required SAS Web API configuration
- SQL Server (if required by the application)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/drashti-shastra-soft/SAS-Public-Portal.git
```

**2. Navigate to the project directory**

```bash
cd SAS-Public-Portal
```

**3. Open the solution**

Open the following solution file using Visual Studio:

```text
DirghDharstiInvestment.sln
```

**4. Restore NuGet Packages**

Restore the required NuGet packages using Visual Studio or the compatible .NET CLI.

**5. Configure Application Settings**

Configure the required API URL, database connection, and other application settings according to your development environment.

Never commit production passwords, API keys, or sensitive configuration values to GitHub.

**6. Build and Run**

Build the solution and select the appropriate web project as the startup project in Visual Studio.

Run the application to launch the public portal locally.
